\begin{abstract}
We present \valen\ (\emph{Verification And Active Logic Engine, Neuro-symbolic}),
an end-to-end system that joins a measured \emph{defensive} thesis with an
\emph{offensive} platform over one typed graph intermediate representation
($\IR$). Defensively, we settle a boundary question with statistical rigor:
spectral, persistent/directed-homology, and discrete-curvature invariants of
program graphs contribute \emph{no information} beyond taint for injection
prioritization (OWASP Benchmark~1.2, $2740$ cases; taint MRR $0.894$, AUC $0.895$,
fused field $0.872$, paired permutation $p=5\times10^{-5}$), yet they are the
\emph{only} signal for authorization (BOLA/IDOR: recall $1.0$ / precision $0.90$
on crAPI), destructive state cycles (GLMY directed homology: $0.97$ vs.\ $0.065$
recall for symmetrized), and trust topology. Offensively, \valen\ is an autonomous
red-team platform --- a multi-user team server spanning reconnaissance, Active
Directory attack-graph analysis, command and control, credential recovery,
phishing and exfiltration --- whose differentiator is a layered
\emph{attack-graph mathematics} that we state and prove: Menger min-cut
chokepoints, min-cost flow, absorbing Markov-chain hitting probabilities solved
exactly by $(I-Q)^{-1}R$, Z3-Optimize bounded-model-checking that synthesizes
minimal-cost ordered exploit plans with AND-preconditions, and a probabilistic
context-free grammar for password guessing. The agent solves $18/18$ documented
crAPI challenges autonomously (including three LLM prompt-injection challenges).
\end{abstract}

\section{Introduction}
\IEEEPARstart{T}{wo} questions organize this work. \emph{First, where do
structural invariants of program graphs carry security information, and where do
they not?} \emph{Second, can the same machinery be turned into a quantitative
planning engine for offensive operations?} The answer to the first is a sharp,
statistically-settled boundary (\S\ref{sec:boundary}); the answer to the second is
an operational platform whose differentiator is mathematics, not scripting
(\S\ref{sec:platform}, \S\ref{sec:math}).

Our contributions are:
\begin{enumerate}[label=\textbf{C\arabic*.},leftmargin=2.2em]
\item A \emph{measured boundary} on geometric priors for injection SAST, with a
  paired permutation test and bootstrap confidence intervals.
\item An \emph{operational authorization invariant} mechanized in Lean~4, a
  structural BOLA/IDOR detector, and a Z3 ownership witness separating
  object-level authorization from authentication.
\item Evidence that \emph{GLMY directed path homology} is the correct cycle
  signal, dominating symmetrized homology.
\item A \emph{measured neuro-symbolic arbitration boundary}: the LLM proposes,
  formal methods dispose.
\item A \emph{multi-language SAST front-end}: one generic taint engine driving
  nine grammars.
\item An \emph{autonomous red-team platform} with an authorization-first model.
\item \emph{Attack-graph mathematics} with proofs: chokepoints, least-cost and
  disjoint plans, exact hitting probabilities, minimal-cost exploit synthesis,
  and a PCFG password prior.
\end{enumerate}

\section{Formal framework}
\label{sec:framework}

\begin{definition}[Typed IR]
\label{def:ir}
A \emph{typed graph} is a directed multigraph $\IR=(V,E,\tau_V,\tau_E,\alpha)$
where $\tau_V:V\to\mathcal{K}_V$ labels vertices (module, function, sink, gate,
principal, \dots), $\tau_E:E\to\mathcal{K}_E$ labels edges (control, data, call,
taint, trust, auth, \dots), and $\alpha:E\to\Sigma^{*}$ attaches attributes such
as a relation name or a cost. Every adapter emits the same $\IR$, so all analysis
layers are engine-agnostic.
\end{definition}

\begin{definition}[Structural field]
\label{def:field}
A \emph{structural field} is a map $V(x):\IR\to\R^{d}$ that fuses the signals of
the algebraic (taint lattice, privilege level), spectral (Fiedler vector),
topological (persistent $H_0,H_1$ and GLMY directed $H_1$), and geometric
(Forman--Ollivier Ricci) layers into a per-node score used for prioritization.
\end{definition}

\begin{definition}[Privilege lattice and auth edge]
\label{def:auth}
Let $F:V\to\N$ be a privilege level. An edge $e=(u,v)$ with $\tau_E(e)=\texttt{auth}$
is an \emph{auth edge} iff $F(u)<F(v)$. A path $\pi=v_0\to\cdots\to v_k$ is
\emph{ungated} if none of its edges is an auth edge.
\end{definition}

\begin{proposition}[No privilege escalation without auth edges]
\label{prop:auth}
If $\pi=v_0\to\cdots\to v_k$ is ungated, then $F(v_k)\le F(v_0)$.
\end{proposition}
\begin{proof}
Every non-auth edge is either intra-level or \emph{downward} in the lattice, i.e.\
for each edge $e=(v_i,v_{i+1})$ on $\pi$ we have $F(v_{i+1})\le F(v_i)$. By
transitivity $F(v_k)\le F(v_0)$. The statement is mechanized in Lean~4 as
\texttt{no\_auth\_bounded}; the soundness of the boolean taint abstraction is
\texttt{prop1\_soundness}. \qedhere
\end{proof}

\begin{definition}[Attack graph and cost]
\label{def:cost}
An \emph{attack graph} is an $\IR$ whose vertices are principals and whose edges
$m\to n$ are \emph{actions} requiring control of $m$ and yielding control of $n$.
A \emph{cost model} is $c:E\to\R_{>0}$ (stealth plus effort; e.g.\
$c(\mathrm{MemberOf})=1$, $c(\mathrm{DCSync})=5$). Given entry set $S$ and target
set $T$, an \emph{attack plan} is a set of edges whose transitive closure connects
some $s\in S$ to some $t\in T$.
\end{definition}

\begin{definition}[Hitting probability]
\label{def:hit}
For a target set $T\subseteq V$, the \emph{hitting probability} $h:V\to[0,1]$ is
\[
h(u)=
\begin{cases}
1 & u\in T,\\
\frac{1}{\deg^{+}(u)}\sum_{v:\,u\to v}h(v) & u\notin T,
\end{cases}
\]
the harmonic measure of $T$ under a uniform random walk on the directed graph.
\end{definition}

\begin{proposition}[Hitting probability is the unique harmonic solution]
\label{prop:hit}
For transient nodes $u\notin T$, the vector $h_T$ satisfies $(I-Q)h_T=r$ where
$Q$ is the transient-to-transient transition matrix and
$r_u=\sum_{v\in T}P_{uv}$; the solution is unique and can be obtained by value
iteration or by Gaussian elimination in $O(|V|^3)$.
\end{proposition}
\begin{proof}
Partition $V=T\uplus U$ (transient $U$). The Bellman equation is
$h_T=Qh_T+r$ with $Q$ substochastic (row sums $\le1$, and $<1$ for any node with
a target neighbour). Hence $I-Q$ is an $M$-matrix, therefore nonsingular, and the
fixed point is unique. Value iteration converges because $Q$ is a contraction on
the transient subspace. \qedhere
\end{proof}

\section{Structural verification}
\label{sec:verification}

\subsection{The boundary on geometric priors}
\label{sec:boundary}
On OWASP Benchmark~1.2 ($2740$ cases with known ground truth) a prioritization
oracle ranks all sink candidates and measures MRR, R@1, NDCG@$k$, plus a paired
permutation test and bootstrap confidence intervals.

\begin{theorem}[Boundary, empirical]
\label{thm:boundary}
For linear injection flaws, the geometric/spectral/topological signals carry no
prioritization information beyond taint: raw taint achieves MRR $0.894$
(AUC $0.895$); the fused structural field achieves $0.872$
($p=5\times10^{-5}$, 95\% CI $[+0.0157,+0.0294]$); spectral ($0.496$) and
topological ($0.500$) are at chance and curvature is below chance ($0.376$).
\end{theorem}

This is a \emph{publishable negative result}: a flat, near-acyclic servlet has no
curvature or persistent topology to exploit, and taint is near-optimal there.
Figure~\ref{fig:boundary} shows the per-signal AUC.

\subsection{Authorization, mechanized and operational}
\label{sec:authz}
Proposition~\ref{prop:auth} is operationalized in three artifacts. (i) The
structural \emph{missing-authorization/BOLA} detector flags a function with an
HTTP source and a resource sink but no auth gate; on a curated 39-case corpus it
reaches recall $1.0$ / precision $0.72$ / F1 $0.837$ where taint scores $0$, and a
baseline ladder shows each requirement earns its keep ($0.46\to0.72$). (ii) The
Z3 verifier checks
$\mathrm{SAT}(\mathrm{owner}(id)\neq session)$ --- an ownership witness separating
object-level authorization from mere authentication. (iii) On crAPI ($44$
operations, $9$ documented BOLA/BFLA endpoints) an object-reference signal
recovers all $9$ (recall $1.0$, precision $0.90$) while the missing-auth check
scores $0$, because every BOLA endpoint \emph{is} authenticated.

\subsection{Directed path homology}
\label{sec:glmy}
Symmetrizing a directed graph is lossy in both directions: a $2$-cycle
$A\to B\to A$ collapses to a single undirected edge (a missed reentrancy), and a
filled triangle becomes a false cycle.

\begin{proposition}[Directed vs.\ symmetrized homology]
\label{prop:glmy}
GLMY directed path homology $H_1$ is a strict superset of symmetrized homology for
detecting destructive cycles: measured recall $1.0$ / precision $0.75$ on a
12-graph state-machine corpus (vs.\ $0.5$/$0.5$ symmetrized) and $0.968$ vs.\
$0.065$ on SmartBugs-curated smart contracts.
\end{proposition}
GLMY returns the concrete $\beta_1$ generator (the cycle's edges) as evidence; its
two false positives are diamond path-space holes, not feedback loops --- a
high-recall, necessary-but-not-sufficient signal.

\subsection{Neuro-symbolic arbitration}
\label{sec:neuro}
On a 38-file corpus ($29$ confirmed findings) the offline heuristic and the
LiteLLM-backed agent agree on detection and ranking on $37/38$ files (agreement
$0.974$), while the LLM changes the CWE on $28\%$ of findings. The architecture is
\emph{LLM proposes, Z3 disposes}; the measurement bounds the LLM's role.

\section{Multi-language SAST}
\label{sec:langs}
One generic taint engine drives nine tree-sitter grammars (C, C++, Rust, C\#,
Go, PHP, Ruby, JavaScript/TypeScript) with per-language profiles declaring
sources, sinks, sanitizers, and auth gates; Python, Java (interprocedural), and
Solidity have dedicated adapters. A canonical registry unifies severity, CWE,
OWASP Top-10, default CVSS~3.1/4.0 vectors, MITRE tactic, and remediation per
category, so every finding is enriched for reporting.

\section{Attack-graph mathematics}
\label{sec:math}

\subsection{Chokepoints via Menger min-cut}
\begin{theorem}[Menger, vertex form]
\label{thm:menger}
The maximum number of internally vertex-disjoint paths from $S$ to $T$ equals the
minimum number of vertices whose removal separates $S$ from $T$.
\end{theorem}
\begin{proof}[Construction]
Split each $v$ into $v_{\mathrm{in}}\to v_{\mathrm{out}}$ of capacity $1$
(unbounded for $v\in S\cup T$), replace each $u\to v$ by
$u_{\mathrm{out}}\to v_{\mathrm{in}}$ of capacity $\infty$, and add a super-source
to $S$ and $T$ to a super-sink. A max flow saturates the unit split edges of a
minimum vertex cut; the saturated edges on the source side of the residual graph
are exactly the chokepoints. \qedhere
\end{proof}

\subsection{Min-cost flow}
Sending $k$ units of flow at minimum cost, with internal vertices of capacity $1$,
yields the $k$ \emph{cheapest vertex-disjoint} attack routes. We implement
successive shortest augmenting paths (Bellman--Ford on the residual graph).

\subsection{Hitting probability}
Proposition~\ref{prop:hit} gives the probabilistic risk ranking; in the toy corpus
an entry with three out-edges and one route to the target scores $\tfrac13$, a
direct entry $1$.

\subsection{Formal synthesis: minimal-cost exploit plans}
\begin{theorem}[Synthesis soundness and optimality]
\label{thm:synth}
Let the transition system be
\[
\mathrm{has}(s{+}1,n)\equiv \mathrm{has}(s,n)
\vee \bigvee_{e:\,m\to n}\bigl(\mathrm{taken}_e\wedge\mathrm{has}(s,m)\bigr),
\]
with entries at step $0$. A satisfying assignment of
\texttt{z3.Optimize} minimizing $\sum_e \mathrm{taken}_e\,c(e)$ under
$\bigvee_{s\le k}\mathrm{has}(s,t)$ is (i) a feasible plan and (ii) minimal-cost
among plans of length $\le k$.
\end{theorem}
\begin{proof}
(i) Follows by induction on the step index: \texttt{has} is monotone and each
\texttt{taken} edge has its source true at the step it fires, so the derived
ordering is a valid execution. (ii) The objective is exactly the plan cost and the
optimizer returns a minimum over the bounded search space. Compound actions
$\{\mathrm{sources}\to \mathrm{target}\}$ add $\bigwedge_{s}\mathrm{has}(s)$ as an
AND-precondition, e.g.\ DCSync requires Domain Admins \emph{and} a session on a
Domain Controller. \qedhere
\end{proof}

\subsection{Password guessing: PCFG}
\begin{definition}[PCFG]
\label{def:pcfg}
Tokenize a password into runs of letters $L$, digits $D$, symbols $S$. A
\emph{base structure} is the sequence of $(class,length)$ pairs (e.g.\
$L_6D_4S_1$); terminals are keyed by $(class,length)$. The probability of a guess
$\sigma$ is
$P(\sigma)=P(\mathrm{structure})\cdot\prod_{t\in\sigma}P(t)$.
\end{definition}
\begin{proposition}[Monotone enumeration]
\label{prop:pcfg}
Best-first expansion over the per-slot terminals, ordered by descending
probability, enumerates guesses in non-increasing $P(\sigma)$ with no duplicates.
\end{proposition}
\begin{proof}
The negative log-probability $-\log P(\sigma)$ is an additive, non-negative
per-slot cost, so Dijkstra over the product lattice (each node expands by
incrementing one slot index) visits guesses in non-decreasing cost; the
\emph{seen} set prevents re-expansion. \qedhere
\end{proof}

\section{Limitations and ethics}
The evaluations are a single real API plus curated corpora, not public benchmarks;
the structural detector over-approximates; the Z3 witness holds under the modeled
semantics; the pure-Python numeric fallback approximates the Rust core; the PCFG
prior is only as good as its corpus. The platform is an authorized-engagement
tool: scope is loopback by default, execution is behind \texttt{--allow-exec},
intrusive actions require operator approval.

\section{Conclusion}
\valen\ contributes a falsifiable boundary result, a mechanized authorization
invariant, the correct cycle signal, a measured neuro-symbolic arbitration
boundary, a multi-language front-end, an autonomous red-team platform, and a
proved attack-graph mathematics. One typed IR joins the defensive and offensive
sides, and every result carries a machine-checkable witness.
