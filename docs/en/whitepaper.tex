\begin{abstract}
\noindent MANIFOLD is a \emph{neuro-symbolic structural-invariant verifier}: an
autonomous agent that mines security specifications (authorization invariants,
state-machine cycles, taint preconditions) from code with an LLM and discharges
them with formal methods (Z3, persistent/directed homology, a mechanized Lean~4
core) --- emitting only \emph{machine-checkable witnesses under the modeled
semantics}. This paper asks one integral question and answers it with a sharp
boundary: \emph{where do the structural invariants of program graphs carry
security information, and where do they not?}

The negative side of the boundary is precise. On linear injection flaws, where a
flat, near-acyclic servlet has no curvature or persistent topology to exploit and
classic taint is already near-optimal, structural priors add nothing: on OWASP
Benchmark~1.2 (2740 cases) raw taint ranks the vulnerable sink best (MRR
$0.894$, AUC $0.895$, beats the fused field with $p=5\times10^{-5}$, add-one over
20000 permutations); spectral ($0.496$) and topological ($0.500$) signals are at
chance and curvature below chance ($0.376$). Hypotheses H1/H2/H3/H5 are
\emph{not supported}. The positive side is where the highest-impact flaws of
modern software live --- BOLA/IDOR (CWE-639), missing authorization (CWE-862),
and destructive state cycles (reentrancy, deadlocks) --- which are
\emph{structural}: the offending data is legitimate, so classic taint is blind
to them, and only the privilege-boundary and state-transition \emph{shape} of the
program gives them away. There the same machinery is the only signal: on a
curated 39-case BOLA/IDOR corpus the structural \emph{missing-authorization}
detector reaches recall $1.0$ / precision $0.72$ / F1 $0.837$ while taint scores
$0$ (its $7$ false positives are the documented over-approximation limit; a Z3
ownership witness separates object-level authorization from mere authentication;
on real data --- OWASP crAPI, 9 documented BOLA/BFLA endpoints --- an API-level
object-reference signal reaches recall $1.0$ / precision $0.90$ where the
missing-auth check scores $0$, because every BOLA endpoint \emph{is}
authenticated);
GLMY directed path homology, benchmarked on 12 state graphs, reaches
recall $1.0$ / precision $0.75$ versus $0.5$/$0.5$ for the symmetrized homology
it supersedes. The
result is a single account --- the same typed graph, privilege algebra, directed
homology and Z3 verifier --- of \emph{which} program relations make structural
invariants informative. We contribute this account, a prioritization-oracle
harness, a reproducible Java pipeline with Z3 witnesses, external validation on
Juliet and real CVEs, and a Lean~4 mechanization of the taint-abstraction
soundness and the no-auth boundedness part of the authorization invariant.
\end{abstract}

\section{Motivation}
Rule-based and semantic static-analysis pipelines are brittle:
they miss novel vulnerabilities and drown analysts in false positives. Two
capabilities are missing:
\begin{enumerate}[label=(\arabic*)]
  \item A \emph{unified, quantitative representation} of ``program structure''
        onto which many \emph{independent} signals can be projected and fused.
  \item A \emph{reasoning loop} that converts a ``suspicious region'' into a
        ``verified finding under the encoded semantics'' --- the LLM supplies the
        intuition, mathematics supplies the verification.
\end{enumerate}
MANIFOLD provides both.

We model vulnerability \emph{candidates} as violations of program invariants
rather than purely syntactic patterns (a broken authorization invariant, a
persistent cycle, a negative curvature chokepoint, a taint flow across a spectral

$V(x)$ ranks regions for the agent to inspect.

\section{The Intermediate Representation (IR)}
\begin{quote}
\textbf{Definition 1 (Program graph).} A \emph{program graph} is a tuple
$G = (V, E, \tau_V, \tau_E, \omega)$ where
\begin{itemize}[leftmargin=1.5em]
  \item $V$ is a finite set of \emph{nodes} (modules, functions, blocks,
        statements, calls, variables, sources, sinks);
  \item $E \subseteq V \times V$ is a set of directed \emph{edges};
  \item $\tau_V : V \to \N_K$ assigns each node a \emph{kind} from
        $K = \{\text{module}, \allowbreak \text{function}, \allowbreak
        \text{block}, \allowbreak \text{statement}, \allowbreak \text{call},
        \allowbreak \text{assign}, \allowbreak \text{variable}, \allowbreak
        \text{parameter}, \allowbreak \text{source}, \allowbreak \text{sink},
        \allowbreak \text{gate}\}$;
  \item $\tau_E : E \to \mathcal{T}$ assigns each edge a \emph{type}
        $\mathcal{T} = \{\text{control}, \allowbreak \text{data}, \allowbreak
        \text{call}, \allowbreak \text{taint}, \allowbreak \text{trust},
        \allowbreak \text{auth}\}$;
  \item $\omega : E \to \R_{\ge 0}$ assigns each edge a non-negative
        \emph{weight} (default $1$).
\end{itemize}
\end{quote}
The IR is the single source of truth. Every adapter (source code, binary, web
API, LLM agent) must produce a program graph; every analysis consumes it. The
schema is language-agnostic and JSON-serializable (the Python and Rust layers
share the identical schema).

\emph{Naming note.} Despite the codename, the object is a \emph{program-analysis
space}: a typed graph together with derived complexes, embeddings and a scalar
field. We do \emph{not} claim it is a mathematical manifold (there is no atlas,
chart or local Euclidean structure); ``manifold'' is used informally, as in
``data manifold''.

\section{Mathematical layers}
For each layer we fix a subgraph by edge type $\tau_E$, then compute structure.

\subsection{Spectral layer (algebraic graph theory)}
For an edge type $t$, define the symmetric \emph{adjacency} $A_t$ and
\emph{degree} $D_t$, and the \emph{combinatorial Laplacian}
\[
L_t = D_t - A_t .
\]
$L_t$ is positive semidefinite; its spectrum
$0 = \lambda_1 \le \lambda_2 \le \cdots$ encodes global structure:
\begin{itemize}[leftmargin=1.5em]
  \item $\lambda_2$ is the \emph{algebraic connectivity} (Fiedler value). Its
        eigenvector $f_2$ --- the \emph{Fiedler vector} --- induces a canonical
        cut $S^+ = \{v : f_2(v) \ge 0\}$.
  \item The \emph{spectral embedding}
        $\Phi^{(d)}(v) = (f_2(v), f_3(v), \dots, f_{d+1}(v))$ maps nodes into
        $\R^d$.
  \item The Cheeger inequality bounds the bottleneck ratio $h(G)$ by
        $\tfrac{\lambda_2}{2} \le h(G) \le \sqrt{2\,d_{\max}\lambda_2}$.
\end{itemize}
\textbf{Signal 1 (spectral anomaly).} The reconstruction error of a node under a
low-rank eigenmap reconstruction, and its distance from the Fiedler cut, are
used as anomaly scores.

\subsection{Topological layer (persistent homology)}
From the program graph we build a \emph{filtration} of simplicial complexes
(e.g.\ a Vietoris--Rips or flag complex over the shortest-path metric, or a
filtration driven by $\omega$). Persistent homology yields, for each dimension
$k$, a \emph{persistence diagram} $\mathrm{Dgm}_k$ of birth--death pairs.
$\beta_0$ counts components, $\beta_1$ counts independent cycles; points far
from the diagonal have high persistence. The \textbf{Mapper} algorithm
(Singh--M\'emoli--Carlsson) builds a navigable \emph{nerve} from a filter
function $f: V \to \R$, producing the map that gives the project its name.

\subsection{Geometric layer (discrete curvature)}
The \emph{Ollivier--Ricci curvature} of an edge $(u,v)$ is
\[
\kappa(u,v) = 1 - \frac{W_1(m_u, m_v)}{d(u,v)},
\]
with lazy random-walk measures $m_u, m_v$ and Wasserstein-1 distance $W_1$.
Negative curvature marks \emph{funnels} through which many shortest paths pass.
The \emph{Forman--Ricci} curvature (unweighted) is $\kappa_F(u,v) = 4 - \deg(u)
- \deg(v)$, cheaply flagging high-degree hubs.

\subsection{Algebraic layer (taint lattice \& authorization order)}
\emph{Taint lattice.} The abstract domain is the powerset lattice of taint tags
$\mathbb{T} = (2^{\mathcal{K}}, \subseteq, \cup, \cap)$, with $\bot = \emptyset$
(clean) and $\top$ (tainted). It forms a Galois connection $(\alpha, \gamma)$
with the concrete collecting semantics; soundness is proved in \S4.6.
\emph{Authorization order.} We keep the authorization model deliberately minimal
--- no category theory is needed. Let $F : V \to \mathbb{N}$ be a
\emph{privilege-level function} on program points (so different points may share a
level; an edge need not raise it); an edge $e=(u,v)$ is an \emph{auth edge} iff
$F(u) < F(v)$ (a strict escalation), and $E_A$ is the set of auth edges. A
\emph{sanitizer} at a point maps every tag to clean. \textbf{Authorization
invariant:} a taint flow reaching a sink is a \emph{violation} when its path
crosses an auth edge and no sanitizer on the crossing segment restores the
invariant. This is stated precisely in \S4.6 (the no-auth boundedness part is
mechanized).

\subsection{Formal layer (symbolic execution \& model checking)}
Symbolic execution computes a path condition $\Phi$ and symbolic state $\sigma$;
an SMT solver checks $\mathrm{SAT}(\phi_{\text{bad}})$, whose model is
a witness under the encoded semantics (not an end-to-end exploit). Reachability is the CTL formula $\mathbf{EF}\,\phi_{\text{bad}}$;
taint propagation is a finite automaton whose accepted language is exactly the
set of source $\to$ sink paths.

\subsection{Formal core: authorization invariant and soundness}
\emph{Small-step semantics of the IR.} A state maps variables to
concrete values; the transition relation $v \xrightarrow{\sigma} v'$ steps
through the IR. The concrete taint collecting semantics $\mathcal{C}$ maps each
point to the set of executions that carry an untrusted value there. The abstract
analysis of \S4 is the function $A$ computed by the transfer functions; the
pair $(\alpha, \gamma)$ satisfies $\alpha(\mathcal{C}(v)) \sqsubseteq A(v)$ and
$\mathcal{C}(v) \subseteq \gamma(A(v))$.

\smallskip
\noindent\textbf{Proposition 1 (soundness of the taint abstraction).} \emph{If the
abstract analysis reports a variable clean, no concrete execution taints it.}

\noindent\emph{Proof scheme.} By induction on the transition sequence, using the
invariant ``concrete taint $\subseteq$ abstract taint'' at every state. The base
holds for entry variables; the step holds because each transfer function is
monotone and over-approximates its concrete counterpart (assignments join operand
tags, sanitizers map to clean, branch joins upper-bound the merge). The guarantee
is contingent on the sanitizer \emph{summary} matching the sanitizer's real
semantics: a wrong summary (claiming to clean what it does not) breaks soundness.
This is exactly the mechanized statement \texttt{prop1\_soundness} (\S4.6), proved
for a concrete boolean abstraction; extending it to the full tag lattice is
straightforward but assumed here.

\smallskip
\noindent\textbf{Proposition 2 (authorization-invariant violation).} \emph{Let
$F : V \to \mathbb{N}$ be the privilege-level function, and let
$p = e_1 \circ \dots \circ e_n : s \to k$ be a path. Write $\mathrm{Auth}(p)$ for
the auth edges on $p$ and $\mathrm{San}(p)$ for the sanitizers on $p$. Then:
(i) if $\mathrm{Auth}(p) = \emptyset$ then $F(k) \le F(s)$ (no privilege
escalation); (ii) if an auth edge $e_i = (v_i, v_{i+1})$ lies on $p$ and no
sanitizer neutralizes the tag before that crossing, then the execution contains an
attacker-controlled privilege-boundary crossing.}

\noindent\emph{Proof.} (i) Each non-auth edge satisfies $\neg(F(u) < F(v))$, i.e.\
$F(v) \le F(u)$, so $F$ is non-increasing along $p$; transitivity gives
$F(k) \le F(s)$. This is the mechanized \texttt{no\_auth\_bounded} (\S4.6). (ii) An
auth edge strictly raises $F$ at the crossing; absent a sanitizer before it, the
tag survives, so the boundary is crossed under attacker control. The statement is
\emph{local} to the crossing: mere presence of an auth edge on $p$ does not imply
$F(k) > F(s)$ --- e.g.\ $0 \to 1 \to 0$ crosses an auth edge yet returns to the
same level. Bounding $F(k)$ (or placing $k$ inside the protected region) needs the
additional assumption $F(k) > F(s)$. (A formula of the
form $F(p)\circ\eta_s \neq \eta_k\circ T(p)$ appeared in an
earlier draft; it was under-typed and is withdrawn --- no natural transformation is
claimed here.) $\square$

\noindent The invariant (ii) is exactly the operational rule H4 (§8/C4): a taint
finding inside an auth-gated function is an authorization violation. Proposition 1
and the no-auth boundedness part (i) of Proposition 2 are \emph{mechanized} in
Lean~4 (core only, no Mathlib) in \texttt{formal/Manifold.lean}:
\texttt{prop1\_soundness} proves the boolean taint abstraction sound against the
tag-collecting semantics (\S3 there), and \texttt{no\_auth\_bounded} proves (i)
(\S4 there). The crossing part (ii) is a semantic definition, not separately
mechanized. The proof checking is part of the reproducibility artifact
(\texttt{scripts/check\_formal.sh}).

\[
V(x) = \sigma\!\Big(\textstyle\sum_i \alpha_i \, s_i(x)\Big),
\]
where $s_i$ are normalized layer signals and $\alpha_i$ weights. To avoid a
\emph{circularity} --- the field that decides \emph{what to verify} must not
depend on verification --- we distinguish two fields:
\begin{itemize}[leftmargin=1.5em]
  \item $V_{\text{prior}}(x)$ fuses only signals computable \emph{before} SMT

  \item $V_{\text{post}}(x)$ additionally consumes the \texttt{formal} (Z3) signal

        pre-verification ranking.
\end{itemize}
In the prototype the weights are \emph{uniform} ($\alpha_i = 1/N$ over the chosen
signals) and $V$ is reported as the raw fused score; calibrating $\alpha_i$ is
future work.

\section{A worked example (end-to-end)}
Consider this ten-line Python fragment:
\begin{lstlisting}
def search(db, query_param):
    sql = "SELECT * FROM users WHERE name = '" + query_param + "'"
    cursor = db.cursor()
    cursor.execute(sql)
\end{lstlisting}
The pipeline produces: (i) an IR with a \texttt{source} node
(\texttt{param:query\_param}), a \texttt{sink} node (\texttt{cursor.execute},
category \texttt{sql}) and a \texttt{taint} edge between them; (ii) the field
$V(x)$ spikes at the sink (taint + formal signals active); (iii) the Z3 symbolic
verifier returns \texttt{SAT} with a model witness under the encoded semantics (e.g.\
\texttt{"x' OR '1'='1"}), proving the sink's argument depends on
the attacker-controlled symbol. The parameterized variant
\texttt{execute(query, (param,))} is correctly \emph{not} flagged, and a
\texttt{@login\_required} gate on the enclosing function upgrades the finding to
an H4 authorization violation (a taint flow crossing an \texttt{auth} edge).

\section{The autonomous LLM agent}
A closed loop: (1) \emph{ingest} into the IR; (2) \emph{embed \& map} ($V(x)$,
spectral embedding, persistence, curvature, Mapper); (3) \emph{hypothesize}
(the LLM proposes candidates from the manifold); (4) \emph{verify} (the formal
layer proves or refutes); (5) \emph{refine} (findings re-weight and re-embed);
(6) \emph{report}. The LLM provider layer targets any OpenAI-compatible endpoint
via \textbf{LiteLLM}. The LLM does not do raw detection: mathematics proposes
regions, the LLM proposes hypotheses, the formal layer proposes proofs.

\section{Design challenges and mitigations}
A design review identified five structural risks. For each we state the
mitigation adopted in the prototype and the open problem.

\textbf{C1 -- The bottleneck paradox.} Negative curvature flags funnels, but
healthy software \emph{deliberately} concentrates flow through auth middleware,
sanitizers, dispatchers and loggers. Reporting these as privilege-escalation
leads yields systematic false positives. \emph{Mitigation:} the agent
discriminates defensive chokepoints (by role) and drops or down-ranks them; the
principled fix is to tag \texttt{trust}/\texttt{auth} edges (already reserved in
the IR) and treat a chokepoint as defensive iff it is the target of an
\texttt{auth} edge. \emph{Open:} learning the defensive/offensive label from data.

\textbf{C2 -- Symmetrization destroys causality.} The combinatorial Laplacian
$L=D-A$ and standard persistent homology act on undirected metric spaces, but
control and data flow are directed: $A$ tainting $B$ is not $B$ tainting $A$.
Symmetrizing can destroy the direction of taint. \emph{Mitigation:} the
prototype implements Chung's directed Laplacian restricted to the largest
strongly connected component; the Perron vector $\pi$ is computed by power
iteration with a small PageRank-style teleportation (damping $\alpha = 0.01$),
which keeps the stationary distribution well-posed on periodic chains. This
operator requires \emph{recurrent} (strongly connected) structure; on a DAG it
yields no informative signal. A DAG certainly has direction --- its causality is
simply delegated to the directed taint/reachability analysis (and, for homology,
to GLMY path homology, \S11) rather than to a stationary-distribution operator,
which cannot represent it without additional structure.
\emph{Implemented:} GLMY directed path homology $H_0,H_1$
(Grigor'yan--Lin--Muranov--Yau), which changes the verdict versus the
symmetrized homology (\S11).

\textbf{C3 -- Cost of optimal transport.} Ollivier--Ricci requires a
transportation LP per edge: $\mathcal{O}(|E|\cdot\text{LP})$, prohibitive beyond
$\sim 10^5$ edges. \emph{Mitigation:} Forman--Ricci
$\kappa_F = 4 - \deg(u) - \deg(v)$ is $\mathcal{O}(|E|)$ and is the default
chokepoint signal; entropy-regularized (Sinkhorn) transport is implemented as the
fast alternative to the exact LP. \emph{Open:} adaptive regularization
schedules for very large graphs.

\textbf{C4 -- Operationalizing H4 (authorization invariant).} A constructive rule
is required. Recall the privilege-level function $F : V \to \mathbb{N}$ and the
auth edges $E_A = \{(u,v) : F(u) < F(v)\}$ from \S4.4; the extractor only needs to
emit the \texttt{auth} edges that mark privilege boundaries. Then a taint flow
$s \to^{*} k$ \emph{violates the authorization invariant} iff its path crosses at
least one auth edge --- i.e. untrusted data enters a protected region without the
boundary neutralizing it. This is a reachability query over
the combined $(\text{data} \cup \text{taint} \cup \text{auth})$ graph, directly
computable and automatable. \emph{Implemented:} an authorization extractor emits
\texttt{gate} nodes and \texttt{auth} edges from privilege-gate decorators, and a
taint finding inside a gated function is reported as an authorization violation.

\textbf{C5 -- Manifold-to-verifier bridge.} Geometric features are
quantitative; Z3 needs exact preconditions. We fix a \emph{grammar}: a
hypothesis is the structured spec \texttt{(sink, source, line, category)}. The
manifold supplies the spec (it knows the sink and line), the LLM supplies the
interpretation (CWE, description, confidence), and the verifier consumes the
spec --- never the LLM prose. This keeps the SMT query precise and reproducible.

The thesis our data supports is more modest. Semantic dataflow (taint) is the
dominant signal on the evaluated corpora; structural invariants provide
\emph{complementary hypotheses}. The open question is whether structural priors
can reduce \emph{verification cost} in regimes where semantic analysis is
incomplete (interprocedural, framework-mediated), and whether they help at very
small budgets.

\section{Threats to validity}
\emph{Internal.} The Java adapter is intraprocedural; OWASP's distractor flows and
Juliet's cross-class variants are therefore measured with an inherent recall gap.
Ground truth is the benchmark's own (OWASP's ``false'' cases are partly
definitional and debatable). \emph{External.} Results cover Java servlets and the
Juliet suite; Python, binaries and LLM agents are implemented but not benchmarked
at the same scale. \emph{Construct.} ``Vulnerable'' is a per-case label; the field
is per-node, so the prioritization experiment is a proxy, not a downstream
exploitability measure. \emph{Conclusion.} The negative result (geometric priors
do not beat taint) is specific to these corpora and signals; it should be
re-tested on path-sensitive, interprocedural analyses and on real CVEs before
being generalized.

\section{Validation and responsible use}
Validation is two-stage. Stage 1 (complete) runs the toy micro-benchmarks of
F1--F7 against known ground truth: every seeded vulnerability is confirmed and
every sanitizer / parameterized-query / argv-form false positive is excluded.
Stage 2 is complete for the Java/OWASP evaluation and ongoing for SARD, binaries
and additional domains; it measures precision/recall of the fused field versus raw
taint over labeled corpora --- experimental validation at scale, distinct from the
completed prototype. The harness is implemented: a
labeled toy benchmark reports precision/recall/F1 for the raw taint pass, the
Z3-verified pass and a \emph{calibrated} field whose weights $\alpha_i$ are
learned by leave-one-out logistic regression over the cheap signals --- on the
toy corpus the calibrated field recovers the reentrancy cycle (topological
signal) that the taint pass misses, raising recall while keeping precision at
$1.0$. A corpus loader accepts a JSON manifest or a ``vulnerable|safe``
directory, so the harness can be pointed at OWASP Benchmark / SARD exports; and
the binary adapter has an optional angr backend (``CFGFast`` + interprocedural
taint) in addition to the zero-dependency objdump path. Running the Java SAST
adapter over the full OWASP Benchmark 1.2 (2740 test cases) gives the naive
baseline: precision $0.515$ / recall $0.426$ / F1 $0.466$ on the seven taint
categories, and precision $0.544$ / recall $0.634$ / F1 $0.586$ over all eleven
categories --- the reference point that the fused field, calibration and the
verifier are meant to improve on. MANIFOLD is a defensive /
authorized-testing tool; we release under the assumption of authorized use and
encourage coordinated disclosure.

\subsection{The prioritization oracle (main experiment)}
The bottleneck of SAST is not \emph{detecting} sinks but \emph{deciding which one

\subsection{Empirical study on OWASP Benchmark 1.2}
We ran the Java SAST adapter over the full corpus and profiled the false
negatives. Three \emph{generalizable} gaps explained most of the loss, and were
fixed (none is tuned to the benchmark):

\begin{enumerate}[label=(\roman*)]
  \item \textbf{Branch-aware taint.} A sequential, path-insensitive pass let a
        null guard (\texttt{if (param == null) param = "";}) clear the taint,
        even though the tainted value survives on the other path. We now
        snapshot both branches and \emph{join} their environments (union of
        tags), the taint analogue of a lattice least-upper-bound.
  \item \textbf{Receiver and state taint.} Sinks such as
        \texttt{statement.execute()} and \texttt{pb.start()} take no argument
        --- the taint lives in the \emph{receiver} object, which was obtained
        from a tainted constructor/mutator. We propagate taint from the
        receiver, and mark a variable tainted when a mutator
        (\texttt{add}/\texttt{put}/\texttt{command}/...) stores a tainted value
        into it.
  \item \textbf{Sink coverage.} The XSS family includes
        \texttt{printf}/\texttt{format}, and only writes to the
        \emph{HTTP response writer} are XSS --- \texttt{System.out.println} of
        tainted data is not. Restricting the XSS sinks to the response writer
        removed a large class of false positives.
\end{enumerate}

The ablation isolates each contribution (precision $P$, recall $R$, F1; taint
categories, 1698 cases):
\begin{center}
\begin{tabular}{lccc}
\toprule
variant & $P$ & $R$ & F1 \\
\midrule
initial naive adapter & 0.515 & 0.426 & 0.466 \\
+ branch-join, receiver/state taint, sink coverage & 0.530 & 0.856 & 0.655 \\
+ XSS response-writer restriction (final) & 0.549 & 0.834 & 0.662 \\
\midrule
final, without branch-join & 0.515 & 0.555 & 0.535 \\
final, without XSS restriction & 0.530 & 0.856 & 0.655 \\
\bottomrule
\end{tabular}
\end{center}
Branch-aware taint is the dominant recall lever ($+0.28$ recall); the
response-writer restriction is the precision lever. The final adapter reaches
$P=0.549$, $R=0.834$, $\mathrm{F1}=0.662$ on the taint categories and
$P=0.572$, $R=0.842$, $\mathrm{F1}=0.681$ over all eleven (crypto/hash are
configuration-driven and partly out of scope). The \emph{residual} errors are
the benchmark's deliberately adversarial ``false'' cases --- debatable
parameterized-query and \texttt{ProcessBuilder}-list cases --- and cross-category
distractor flows: precisely the precision that the topological/spectral signals,
the Z3 verifier and the calibrated field are designed to recover.

\subsection{Closing the Z3 row (Java verification)}
We implemented a Z3-backed Java symbolic verifier (bounded, branch-merging,
string semantics; sanitizers as contracts) that confirms or refutes each taint
flow and emits a machine-checkable \emph{witness} under the modeled semantics. Measured on the seven taint categories
(1698 cases) it reproduces the adapter exactly ($P=0.549$, $R=0.834$,
$\mathrm{F1}=0.662$, $J=+0.057$) while adding per-finding witnesses. The honest
conclusion: \textbf{the formal layer adds machine-checkable witnesses under the
\emph{modeled} semantics, not precision, on this benchmark} --- a witness proves
satisfiability inside the model (which abstracts library summaries and framework
behaviour), not end-to-end exploitability of the real program. The residual false
positives are adversarial/definitional (debatable parameterized-query cases), not
spurious symbolic paths; catching them requires modelling the benchmark's own
semantics, not stronger SMT.

\subsection{Cross-corpus transfer (Juliet)}
To test transferability we ran the OWASP-tuned adapter on the \emph{Juliet Java}
test suite (find-sec-bugs mirror; each test case concatenated with its
flow-variant files). On 264 cases across five CWEs it scores
$P=0.333$, $R=0.562$, $\mathrm{F1}=0.419$: detection is partial and precision
collapses on the ``good'' variants. The reason is structural, not a tuning
artifact --- Juliet splits source and sink across \texttt{\_a}/\texttt{\_base}/
\texttt{\_bad} classes, so correct analysis requires \emph{interprocedural}
taint, which the intraprocedural adapter does not provide.

\subsection{Interprocedural taint: necessary, not sufficient}
We added a context-insensitive interprocedural fixpoint
(\texttt{java\_interproc.py}): a callee parameter becomes tainted if some call
site passes tainted data to it, and a call becomes tainted if its callee returns
tainted data; the fixpoint is iterated to convergence. On Juliet it raises recall
$0.562\to0.750$ and F1 $0.419\to0.490$ (CWE78/CWE90 recover from $0.000$ to
$0.750$). \emph{On OWASP it is neutral} (taint F1 $0.662\to0.656$): the
interprocedural pass adds recall ($0.834\to0.856$) but also coarse
parameter-driven false positives, so precision drops, and we union the pass with
the full intraprocedural adapter for coverage parity. The lesson is precise:
interprocedural reachability is \emph{necessary} for cross-class flows but
\emph{not sufficient}. We then added \emph{caller-context sensitivity} with
per-context return summaries: it provably prunes a synthetic class of
return-driven false positives (a value returned from a tainted context no longer
taints a clean caller's call), yet it leaves OWASP and Juliet \emph{unchanged}
(F1 $0.656$ and $0.490$). The real levers are therefore not context but
(a) framework/library summaries and (b) fine-grained return precision --- not more
geometry.

\subsection{Framework summaries}
Guided by the CVE evidence, we added an explicit framework/library summary layer:
\emph{attribute-style sources} (\texttt{request.GET}, \texttt{request.POST},
\texttt{request.args}, \texttt{request.form}, \texttt{self.request.POST}) and
\emph{ORM/template sinks} (\texttt{RawSQL}, \texttt{raw}, \texttt{extra},
\texttt{text}, \texttt{render\_template\_string}, JPA \texttt{createQuery}). With
\emph{positional} sink summaries (only arg~0 of a query/code call is dangerous),
the analyzer now sees application-level flows it previously missed --- Django
query-parameter SQL injection, Flask SSTI, JPA injection --- while keeping
parameterized queries and literal templates safe. This is the concrete lever the
CVEs pointed to. It does not move the aggregates, but for two different reasons:
OWASP/Julet failures are mostly \emph{structural} (cross-method flows that need
interprocedural analysis), whereas the unresolved CVEs are \emph{framework-internal}
(the vulnerable logic lives inside the framework itself, with no
application-level source).

\subsection{Scalability of each kernel}
We timed every kernel on synthetic graphs (log--log, Fig.~\ref{fig:scale}).
\textbf{Forman--Ricci} ($0.6$\,ms @ $10^3$ edges $\to 55$\,ms @ $10^5$) and
\textbf{Mapper} ($0.5\to56$\,ms) are near-linear. \textbf{Persistent homology} is
super-linear ($11$\,ms @ $10^3 \to 1.1$\,s @ $10^4 \to 123$\,s @ $10^5$) because
the fundamental-cycle extraction BFSes the spanning forest per cycle; a
persistence-aware union--find would make it near-linear. \textbf{Sinkhorn}
($0.71$\,s @ $10^3 \to 16.4$\,s @ $5\times10^3$) and \textbf{exact
Ollivier--Ricci} ($34$\,ms @ $200 \to 720$\,ms @ $10^3$) are quadratic, so the
latter is only for small graphs (the reason Forman--Ricci is the default,
\S8/C3). The \textbf{dense spectral and directed Laplacians} are cubic
($26$\,ms @ $300 \to 1.7$\,s @ $1200$ nodes) and \emph{cannot} reach $10^5$
nodes without the sparse solvers planned in F2. The practical envelope today is
$\sim10^5$ edges for the near-linear signals, which covers the corpora used here.

\subsection{Real CVE fixes}
We ran the vulnerable-vs-patched comparison on real CVE fix commits drawn from
OSV / GitHub Security Advisories (\texttt{benchmarks/run\_cves.py}; the harness
reconstructs the \emph{before} revision by reverse-applying the commit diff to
the commit's raw content, so it needs no API quota). On 22 CVEs and 46 changed
source files, \textbf{3 files resolved a finding}: they are \texttt{eval}
injections --- \texttt{senaite.core} (CVE-2026-54569; \texttt{value = eval(value)}
on a method parameter) and \texttt{xinference} (CVE-2026-61539;
\texttt{eval(text)} on LLM output) --- plus a partial resolution in
\texttt{nltk} (CVE-2026-79676) --- flagged in the vulnerable revision and
clean in the patch. The remaining CVEs are mostly \emph{framework-internal} or
non-taint fixes (Django ORM SQL injection, Jinja, requests, GitPython, NLTK
argument-injection and integrity checks): the flow is indirect or outside our
sink model, so the adapter sees nothing. This mirrors the Juliet result and
locates the frontier precisely: MANIFOLD already catches application-level
\texttt{eval}/\texttt{exec}/deserialization fixes; framework-mediated flows need
interprocedural, context-sensitive, library-aware analysis.

\subsection{Directed path homology (GLMY)}
We implemented Grigor'yan--Lin--Muranov--Yau \emph{path homology} $H_0,H_1$ over
the directed 1-skeleton (\texttt{core/src/path\_homology.rs}): $\Omega_2^\partial$
is the set of allowed 2-paths whose long edge is allowed and non-degenerate
($u\neq w$), and ranks are computed by Gaussian elimination. Direction changes
the verdict. On \texttt{reentrancy.py}, undirected homology reports $\beta_1=1$
(the \texttt{withdraw}/\texttt{read\_balance}/\texttt{update\_balance} triangle),
while GLMY reports $\beta_1=0$: the transitive 2-paths through the apex
\texttt{withdraw} fill the \texttt{read\_balance}$\leftrightarrow$\texttt{update\_balance}
2-cycle. On an isolated 2-cycle $A\leftrightarrow B$ the roles invert (GLMY
$\beta_1=1$, undirected $\beta_1=0$), and the analyzer returns the $H_1$
\emph{generator} itself --- the directed cycle as the edge list
$\{A\to B,\;B\to A\}$ --- so the invariant is actionable, not just a number.
Symmetrization (C2) is therefore \emph{not}
innocuous: the directed invariant is a genuinely different, and sometimes
opposite, signal.

\subsection{LLM ablation}
We ran the agent twice over a varied corpus of 38 Python files (29 with a
confirmed finding, spanning command / code-exec / SQL / deserialization /
path-traversal / file-write / logging / SSTI, plus safe and gated variants):
offline (heuristic hypothesizer) and online through the local \textbf{LiteLLM}
proxy (DeepSeek \texttt{flash}, OpenAI-compatible \texttt{/v1}). The
\emph{detection} and \emph{ranking} axes are invariant: the confirmed finding
sets and their confidence ordering agree on $37/38$ files (agreement $0.974$),
because the SMT verifier --- not the LLM --- is the arbiter. The single mismatch
is a \texttt{compile} code-exec case where the LLM's hypothesis is itself
nondeterministic (sometimes empty), so it occasionally fails to re-propose the
finding rather than changing it. The \emph{interpretation} axis changes: on $8$
of the $29$ confirmed findings ($28\%$) the LLM assigns a different, usually
more specific CWE (e.g.\ CWE-674 ``Uncontrolled Recursion'' for the reentrancy
cycle vs.\ the heuristic's generic label), and produces more concise titles.
This larger controlled ablation (38 files,
\texttt{benchmarks/run\_llm\_ablation.py}) confirms the arbitration boundary at
scale: \emph{the LLM adds interpretability and reporting, not detection or
ranking} --- the neuro-symbolic split holds with a small, measured nondeterminism
leak. A complementary \emph{spec-mining} probe
(\texttt{benchmarks/run\_spec\_mining.py}, $n=8$) asks the LLM to state the
security precondition each snippet must enforce: it mines a plausible invariant
in every case (hallucination rate $0$) with $0.50$ mean token-recall against
hand-written ground truth --- the LLM proposes structured specs, but their
verification remains Z3's job. A Java/OWASP-side ablation is future work.

\subsection{Dual binary backend}
The binary adapter ships two interchangeable backends that emit the same IR:
(i) a zero-dependency \texttt{objdump}-text path (function labels $+$ \texttt{call}
edges $+$ interprocedural taint reachability) and (ii) an \emph{optional}
\texttt{angr} backend (\texttt{CFGFast} recovery of the interprocedural call graph
$+$ the same taint reachability), selected by \texttt{--adapter angr-binary}. The
fast path keeps MANIFOLD usable without heavy dependencies; the angr path
recovers control flow that disassembly heuristics miss. This parity is the
substrate for future ELF/PE benchmarks from SARD.

\section{Structural invariants across domains}
The two results so far are two sides of one boundary, not two projects. On one
side (linear injections) a flat, near-acyclic servlet has no curvature or
persistent topology to exploit, and classic taint is already near-optimal --- so
structural priors add nothing. On the other side the offending data is
legitimate and only the \emph{structure} of the program --- its privilege
boundaries and state transitions --- reveals the flaw, so structure is the
\emph{only} signal. The same machinery (typed graph, privilege algebra, directed
homology, Z3) spans both; what changes is the program relation being modelled.
This section surveys the four domains where conventional static analysis is
blind and where each mathematical layer has a natural home.

\subsection{Authorization invariants: BOLA / IDOR / BFLA}
Broken Object Level Authorization (BOLA/IDOR, CWE-639) and missing
authorization (CWE-862) top the OWASP API Security Top~10, and classic taint
cannot see them: the object selector is a \emph{clean} value (an integer id,
often cast), the sink is an ordinary query, and the bug is that user~A reads
user~B's data --- there is no ``dirty'' data to track. The modeled object is a
\emph{multipartite} graph: the API surface (OpenAPI operations), the backend
endpoints, the permission decorators (\texttt{gate} nodes) and the data models,
as produced by the OpenAPI adapter (\texttt{manifold.ingest.web}), which now
also flags an operation that declares a sensitive sink but \emph{no} security
scheme (CWE-862 at the API-design level). The signal is the complement of the
mechanized \texttt{no\_auth\_bounded} invariant: a directed path from a public
entry point to a protected resource with \emph{no} strict authorization edge
where one is required. MANIFOLD implements this as the \emph{missing-authorization
/ BOLA} detector (\texttt{manifold.analysis.authorization.bola\_idor\_candidates}),
and closes the loop with a \emph{Z3 ownership witness}
(\texttt{manifold.analysis.bola\_verifier}): it checks
$\mathrm{SAT}(\,\mathrm{owner}(object\_id)\neq session\_user\_id\,)$ under the
modeled semantics, so a vulnerable endpoint yields a concrete witness (attacker
session reads the victim's object) while an ownership-scoped endpoint is UNSAT.
This makes explicit a nuance the detector alone cannot: an \emph{authentication}
gate (\texttt{login\_required}) does \emph{not} block BOLA --- the endpoint is
still SAT unless an object-level \texttt{owner} predicate is present. On a
curated corpus of 39 cases (\texttt{examples/python/bola/},
\texttt{examples/python/bola\_corpus/}, evaluated by
\texttt{benchmarks/run\_bola.py}) taint reports \emph{zero} findings on the
vulnerable cases while the structural detector reaches \textbf{recall $1.0$} at
\textbf{precision $0.72$} (F1 $0.837$, 95\% CI $[0.54,0.89]$). An ablation ladder
shows each structural requirement earns its keep: all-positive $0.46$, sink-only
$0.49$, source+sink $0.56$, and the full detector $0.72$, at constant recall
$1.0$ --- and the 7 false positives are the documented over-approximation limit
(parameterized/sanitized/unused-source). This transfers to \emph{real data}: on
\textbf{OWASP crAPI} (a deliberately-vulnerable API; 44 operations, 9
BOLA/BFLA endpoints labeled from the official challenge documentation), the
API-level object-reference signal reaches \textbf{recall $1.0$ / precision
$0.90$ / F1 $0.947$} --- and crucially, all 9 BOLA endpoints \emph{are}
authenticated, so a missing-security-scheme check scores recall $0$ on them:
BOLA is invisible to the ``is it authenticated?'' question and only the
object-level structure gives it away. It is precisely the regime where taint
provably scores $0$ and structure is the only signal.

\subsection{State machines, concurrency and protocols: directed homology}
In a servlet there are no state cycles; in smart contracts, lock-acquisition
protocols and concurrency controllers the worst flaws \emph{are} destructive
feedback loops (reentrancy, deadlocks, illegal transitions such as
\texttt{Unauthenticated} $\to$ \texttt{Authenticated} skipping signature
validation). The modeled object is the \emph{state-transition graph} (the
interprocedural CFG extended with external calls and global-store mutations).
The persistent directed $H_1$ generator of GLMY path homology is the exact
signature of a reentrancy cycle --- and, as \S4.2 showed, symmetrization is
\emph{not} innocuous: undirected homology can report $\beta_1=1$ where GLMY
reports $0$ (a triangle filled by an apex) and vice versa. We now \emph{measure}
this on a 12-graph labeled corpus (\texttt{benchmarks/run\_state\_glmy.py}):
GLMY reaches \textbf{recall $1.0$ / precision $0.75$}, while the symmetrized
homology scores recall $0.5$ / precision $0.5$ --- it misses the 2-cycles
($A\to B\to A$ collapses to a single undirected edge) and emits false cycles on
filled triangles. The two GLMY false positives are ``diamond'' path-space holes
(two independent paths converging), not feedback loops, so GLMY is a
high-recall, necessary-but-not-sufficient directed signal that dominates the
symmetrized baseline on both axes. On a synthetic lock-acquisition state cycle
(\texttt{examples/state\_machine/lock\_cycle.json}) the directed analysis
extracts the concrete generator $[\,s_0\!\to\!s_1,\ s_1\!\to\!s_2,\
s_2\!\to\!s_0\,]$ with $\beta_1=1$ --- a finding with no taint analogue.

\subsection{Trust topologies, IAM and lateral movement}
In cloud environments (AWS/Azure/Kubernetes) the worst breaches come from
privilege-escalation \emph{chains} and lateral movement (a compromised role in a
frontend service assuming a secondary role with access to a secret bucket). The
modeled object is the \emph{identity-and-permission graph} (users, IAM roles,
trust policies, services, network resources), ingested by the \texttt{iam}
adapter (\texttt{manifold.ingest.iam}) and analyzed by
\texttt{manifold.analysis.trust}. Here the Fiedler cut
($\lambda_2, f_2$) optimally partitions the trust domains (e.g.\ DMZ vs.\ core);
edges that cross the cut without intermediate controls surface as spectral
anomalies at the trust boundary, and Forman--Ricci curvature --- far from a
detection error --- \emph{isolates the critical privilege bridges}: a strongly
negative $\kappa_F$ edge is the sole connector between two disparate trust
subnets (the ideal attacker pivot). On a demo graph
(\texttt{examples/iam/demo.json}) the analysis flags the app$\to$data
\texttt{assume} as the most-negative bridge ($\kappa_F=-1$) and surfaces the
secret bucket on the Fiedler boundary. The agent then hands the suggested paths
to Z3, which resolves the IAM-policy combinatorics to confirm whether the
role-assumption chain is viable.

\subsection{Security of autonomous agents and LLMs}
Modern systems wiring LLMs to external tools (APIs, databases, shell, email)
face \emph{confused-deputy} and indirect prompt-injection attacks. The modeled
object is the \emph{tool-use graph}: user, model, context memory and external
tools at different privilege levels, with edges typed \texttt{untrusted\_input}
(web data, read mail) and \texttt{privileged\_execution} (drop a database, issue
payments, run commands). The flaw is an authorization-invariant violation: an
untrusted-input flow reaching a privileged-execution tool without an explicit
sanitization or human-confirmation \texttt{gate}. This is exactly what the
\texttt{llm-agent} adapter (\texttt{manifold.ingest.llm\_agent}) already
detects: a dangerous tool reachable from user input with no approval gate is a
finding.

MANIFOLD is thus repositioned as a \emph{formal engine for structural invariants
and business logic}, not a competitor to Semgrep/CodeQL on local SQLi/XSS
patterns. (1) It \emph{abandons a sterile competition}: it does not try to beat
taint on a 20-line servlet. (2) It \emph{attacks what nobody solves}: design
flaws, privilege coherence, concurrent protocols and agent architectures, where
syntactic rules are silent because the code, line by line, looks legitimate.
(3) It \emph{keeps the software intact}: the typed IR, the Rust kernels, the
Lean~4 verification, the Z3 orchestrator and the neuro-symbolic agent are all
preserved, applied over the right relation graph. The narrative is therefore not
``geometry lost to taint'' but a single account of \emph{which} program relations
make structural invariants informative: a rigorously established negative
boundary on linear injection SAST, and a positive one on the architectural flaws
where taint is blind --- both sides backed by working code and measured data.
